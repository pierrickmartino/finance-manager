## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on pierrickmartino/finance-manager, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` plus `docs/adr/`. See `docs/agents/domain.md`.

### Design system

Styling any page or component: read `docs/design-system.md` first, then style with its tokens and the `src/components/surface.ts` primitives. The app is light only.
